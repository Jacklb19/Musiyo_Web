# Musiyo Web

Aplicación web pública del museo virtual Musiyo Bëtsknaté. Este repositorio alojará el frontend React con catálogo y fichas culturales para computador y celular, y el acceso al recorrido Unity WebGL desde computador.

## Estado

El repositorio está preparado, pero la aplicación React todavía no se ha inicializado. El proyecto Unity se mantiene en su repositorio separado y la API en `Musiyo_API`.

## Alcance previsto

- Portada, catálogo, búsqueda y filtros sobre contenido aprobado y autorizado.
- Fichas en español con fuentes, créditos, restricciones y alternativas accesibles.
- Página de recorrido de escritorio con puente de identificadores de recorrido, punto y elemento hacia Unity.
- Corrección limitada de título, descripción e interpretación para el Validador Cultural autenticado.

Toda información pública vendrá de la API. El navegador no llevará claves privadas ni decidirá por sí mismo si un contenido está autorizado. El build WebGL generado no se versionará aquí.
